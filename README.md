# 지구를 지켜ZOOM! 나만의 생태동물 캐릭터 디자이너

초등학교 3학년용 무료 정적 웹앱입니다. 첨부 이미지 ZIP에 실제로 들어 있는 **18종 × 각 5개 = 총 90개 PNG**를 읽어, 동물을 검색하고, 동작을 선택하고, SVG 스티커를 꾸민 다음 PNG로 내려받습니다. 생태카드 및 보호 메시지 작성 기능은 없습니다.

## 포함된 자료와 품질 상태

| 그룹 | 동물 | 파일 | 해상도 / 특성 |
| --- | --- | ---: | --- |
| A: 고해상도 | 황제펭귄, 회색늑대, 고릴라, 레서판다 | 20 | 1254×1254 PNG |
| B: 포스터 분리 시안 | 나머지 14종 | 70 | 576×576 PNG. 크기만 576px이며 그림 자체는 포스터에서 분리된 저해상도 시안으로 일부 글자 흔적, 잘림, 흐림 가능 |

**배경 주의:** 황제펭귄과 회색늑대의 원본 10개는 RGB 포맷으로, 흰 배경을 포함합니다. PNG로 저장해도 그 영역이 자동으로 투명해지지 않습니다. 나머지 원본은 투명 영역이 있지만, 70개 분리 시안에는 테두리 등 잔여물이 있을 수 있습니다. **20개 고해상도라고 모두 투명한 것은 아닙니다.** 원본 이미지의 윤곽 또는 품질을 앱이 새로 만들어내지는 않습니다.

## 실행 및 배포

### GitHub Pages (권장)

1. 제공된 프로젝트 ZIP을 압축 해제합니다.
2. ZIP의 **최상위에** `index.html`, `style.css`, `app.js`, `animals.json`, `stickers.json`, `assets` 폴더가 있는 상태로 GitHub 저장소에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
4. Branch에서 `main`, 폴더에서 `/ (root)`를 설정한 뒤 게시 URL을 사용합니다.
5. 로딩이 안 된다면 프로젝트 폴더를 한 단계 더 중첩해 올리지 않았는지 확인합니다.

학생 계정, 개인정보, 서버, 외부 이미지 검색, 유료 API는 필요하지 않습니다. 정적 파일을 제공하므로 학급 단위로 동시 접속할 수 있지만, 실제 학교 네트워크에서 27대 동시 접속 실측은 별도 확인이 필요합니다.

### 컴퓨터에서 시험

압축을 푼 프로젝트 폴더에서 `python -m http.server 8000` 명령을 실행하고 Chrome에서 `http://localhost:8000`을 엽니다. 보안 정책 때문에 `index.html`을 파일로 직접 더블클릭하면 `animals.json` 등을 읽지 못할 수 있습니다.

## 사용 방법

1. 동물 이름으로 검색하거나 18종 목록에서 선택합니다.
2. 위쪽의 동작 5개 가운데 하나를 클릭합니다.
3. 오른쪽 **소품 / 표정 / 무늬**에서 스티커를 추가합니다.
4. 편집 화면에서 캐릭터 또는 스티커를 클릭하고 드래그합니다. 선택된 객체를 이동, 확대·축소, 회전, 뒤집기, 삭제, 맨 앞으로 보내기 할 수 있습니다.
5. **색감** 탭에서 원본 사진 레이어에 밝기·채도·필터를 적용할 수 있습니다.
6. **PNG 이미지 저장**으로 편집 테두리를 제외한 900×900 PNG를 내려받습니다. 브라우저 캔버스의 투명 영역은 PNG에 유지됩니다.
7. **작업 저장 / 불러오기**는 JSON 형식으로 현재 동작과 꾸미기 상태를 보관합니다. 업로드해 교체한 이미지가 있다면 그 데이터도 JSON에 저장됩니다.

## 나중에 동물 이미지를 바꾸는 방법

이미지는 `assets/animals/<영문동물ID>/01.png`부터 `05.png`까지 저장되어 있습니다. 다음 파일 중 하나를 같은 이름으로 덮어 쓰고 GitHub에 다시 업로드하면 됩니다.

- `assets/animals/snowleopard/03.png`: 눈표범 3번 동작
- `assets/animals/penguin/01.png`: 황제펭귄 기본 동작
- `assets/animals/cheetah/05.png`: 치타 5번 동작

기존 이미지를 교체할 때 **동물별 5개 파일과 PNG 파일명·경로는 그대로 유지**하는 것을 권장합니다. 품질과 해상도 라벨도 정확하게 보이게 하려면 `animals.json`의 해당 항목에 `quality: "high"`, `width`, `height`, `hasTransparency`, `backgroundStatus`를 새 원본에 맞게 수정해야 합니다. 실제 배경이 흰색이면 `hasTransparency`를 `false`로 설정합니다. 이미지를 파일명만 바꿔 추가하는 경우에는 `animals.json`의 `path`를 함께 수정해야 합니다.

교사용 **현재 그림 교체하기** 버튼은 현재 학생의 브라우저에만 적용되는 임시 기능입니다. 학급 전체에 영구 배포하려면 `assets/animals/` 파일과 `animals.json`을 수정해 다시 게시해야 합니다.

## 프로젝트 구조

```text
index.html              학생용 UI
style.css               반응형 화면 디자인
app.js                  검색·꾸미기·캔버스 PNG 저장·작업 JSON
animals.json             18종 및 실제 90개 파일의 메타데이터
stickers.json            30종 SVG 스티커 목록
assets/
  animals/              동물별 폴더, 01.png~05.png
  stickers/             독립 SVG 소품·표정·무늬 30종
README.md                이 문서
```

## 실제 사용 전 확인할 내용

- 저해상도 70개 이미지는 포스터에서 추출한 시안으로 **웹앱이 작동해도** 수업용 캐릭터 품질을 보장하지 않습니다.
- 원본 10개의 흰 배경을 자동으로 제거하지 않습니다. 흰 배경 없는 고화질 PNG로 교체하세요.
- 학생이 검색·꾸미기·저장하는 기능 자체는 외부 API와 관계없이 브라우저에서 실행됩니다.
- 기존 동물 목록이 멸종위기 등급을 의미하지 않으며, 웹앱은 법적 멸종위기종 분류를 표시하지 않습니다.
